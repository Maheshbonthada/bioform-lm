HOW TO HANDLE FIGURES IN SCHOLARONE
═══════════════════════════════════════════════════════════════════════════════

ScholarOne may ask you to upload figures separately. If so:

OPTION A (Recommended): Use figures from PDF
────────────────────────────────────────────
1. Open: ../Manuscript/BioForm-LM_Manuscript.pdf
2. Screenshot or extract each figure using a PDF tool
3. Save as individual PNG/PDF files
4. Upload to ScholarOne "Figures" section

OPTION B: Use figures from artifact
──────────────────────────────────────
Figures are also available as publication-quality SVG in an interactive artifact:
URL: https://claude.ai/code/artifact/8656c162-b14e-46e0-b60a-9df8e48827c6

You can:
1. Open the artifact URL
2. Right-click each figure
3. Save as PNG/SVG
4. Upload to ScholarOne

OPTION C: Use embedded figures
───────────────────────────────
Many journals (including Bioinformatics) accept figures embedded in the PDF.
If ScholarOne doesn't require separate uploads, your manuscript PDF is complete
as-is with all figures embedded.
