SOLUTION:
  ✓ Reset password (click "Forgot Password")
  ✓ Check spam folder for reset email
  ✓ Try incognito/private browsing mode
  ✓ Contact ScholarOne support: https://support.clarivate.com/

PROBLEM: Manuscript not formatting correctly
SOLUTION:
  ✓ Re-export to PDF (from Word: File > Save As > PDF)
  ✓ Check that PDF is text-searchable (not scanned image)
  ✓ Ensure fonts are embedded (check in PDF properties)
