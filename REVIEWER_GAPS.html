🔴 Critical Issues (Rejection-Level)

Without fixing these, paper will be rejected despite solid code.

1. NO REAL DATA EVALUATION
BioFormBench exists but is never used
"You trained on synthetic data only. How do you know this works on real proteins? Show LOPO results on BioFormBench."
Current state: scripts/evaluate.py is a placeholder
What's needed: Implement full LOPO CV on 20-50 real formulations
Impact: Without this, paper is "transformer on synthetic data" — not novel
BLOCKING
⏱️ Fix time: 3-5 days (1-2 for data curation, 2-3 for implementation)
2. CRITIC CIRCULAR TRAINING
Critic trained on simulator → evaluated on simulator predictions
"Your critic just memorized the simulator. How is this better than using the simulator directly? Where's the evidence the critic adds value?"
Current state: Critic trained on simulator outputs, scores generated recipes
What's needed: Ablation showing critic > simulator scoring; validate critic on real data
Impact: Core novelty claim is suspect without validation
BLOCKING
⏱️ Fix time: 1-2 days (add simulator-direct baseline to ablations)
3. NO FAIR BASELINES
Comparing RF/SVM on 10-dim features to generative model on sequences
"You're comparing apples to oranges. Your predictive baselines use hand-crafted features while your model uses learned representations. Make a fair comparison."
Current state: Baselines use FeatureExtractor (different feature space)
What's needed: Fair baseline: sequence-input predict-next-token MLP; compare on same tokenized input
Impact: Results could be inflated due to unfair baseline comparison
BLOCKING
⏱️ Fix time: 1-2 days (implement sequence-input baseline classifier)
4. NO STATISTICAL RIGOR
Single training run, no error bars, no significance testing
"You show one model trained once. LOPO has one test set. No confidence intervals. How do I know these aren't noise?"
Current state: Results from single seed (42)
What's needed: Multi-seed (≥3) LOPO evaluation, report mean ± std, t-tests between baselines
Impact: Results lack credibility without uncertainty quantification
BLOCKING
⏱️ Fix time: 2-3 days (multi-seed runs in parallel)
5. SIMULATOR NOT VALIDATED
Mechanistic simulator used but never checked against real data
"Your simulator combines DLVO + Lumry-Eyring + heuristics. Has this been validated? What's the error rate?"
Current state: Simulator generates synthetic training data; no validation step
What's needed: Run simulator on real BioFormBench formulations, compare predictions vs published outcomes
Impact: Entire synthetic pretraining pipeline is unvalidated; could be training on garbage
BLOCKING
⏱️ Fix time: 2-3 days (for 5-10 proteins from BioFormBench)
